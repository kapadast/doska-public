# Доска

Личная доска задач, привычек, заметок и развития навыков.

## Запуск

1. Установите Python 3.10 или новее.
2. Запустите `python server.py`.
3. Откройте `http://127.0.0.1:8765`.

При первом запуске используется пустой файл `example-board.json`.

## Данные и секреты

Рабочие данные, база SQLite, резервные копии, пароли и ключи не должны попадать в git. Для них уже настроен `.gitignore`.

Переменные запуска перечислены в `.env.example`. Реальные ключи храните вне репозитория.
